# Coffee - shop - sales - analysis

## 📊 Project Overview

The *Coffee Shop Sales Analysis* project explores retail transaction data through an interactive Excel dashboard to uncover meaningful insights that improve store performance, customer engagement, and sales strategies. This project demonstrates strong analytical thinking, data cleaning using *Power Query*, and visual storytelling using *Excel Dashboard*.

## 🎯 Objective
To analyze retail sales data and generate actionable insights that help optimize:
- Product offerings
- Store-level performance
- Customer behavior analysis
- Sales and marketing strategies

---

## 🔍 Key Insights

- 💰 *Total Sales*: $698,812.33  
- 👥 *Total Footfall*: 149,116  
- 📦 *Average Order per Person*: 1.44  
- 🕒 *Peak Sales Hours*: 8 AM – 11 AM  
- 📍 *Top Performing Store*: Hell’s Kitchen ($236,511.17 in sales)  
- 🥇 *Best-Selling Product*: Barista Espresso  
- 📅 *Busiest Weekday*: Friday  
- 🍵 *Most Popular Category*: Coffee (39% of total sales)

---

## 🛠 Tools & Technologies Used

- *Microsoft Excel* – Dashboard design, formulas, data visualization  
- *Power Query* – Data transformation, cleaning, and loading  
- *Pivot Tables & Charts* – For summarizing key metrics  
- *Data Analytics* – Trend analysis and business intelligence techniques  

---

## 📈 Dashboard Highlights

- *Time Trends*: Quantity ordered by hour  
- *Category & Size Sales Distribution*: Pie charts for visual breakdown  
- *Location Analysis*: Store-wise sales and footfall  
- *Top Products*: Highest grossing items  
- *Weekday Orders*: Order pattern across different days  
- *Core KPIs*: Displayed prominently (Sales, Footfall, Avg. Bill)
